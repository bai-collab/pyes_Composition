# 一封信有五個部分——三年級應用文（書信）第一集（格式骨架，表徵版）

- 觀眾：國小三年級學生（三上應用文書信類，題目〈給老師的一封信〉〈給偶像的一封信〉〈給爸爸的一封信〉）。
- 本集定位：應用文第一集。寫信是寫給**一個人**看的；一封信照順序有五個部分：**稱謂語、正文、祝福語、署名、日期**；正文裡面先說一件事、再說想法、最後總結。依 README 第 5 節：表徵優先、文字精簡；每個部分掛工作牌（守門第⑤條）。
- 學完能說出：
  1. 書信是寫給一個人看的文章。
  2. 一封信由上到下：稱謂語（叫對方）→ 正文（想說的話）→ 祝福語（祝福對方）→ 署名（誰寫的）→ 日期（哪一天）。
  3. 正文可以先說一件事，再說想法，最後總結。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g3-08-source-excerpts.md`）：研習講義 S1（題目、週規劃、書信格式與信封格式的名稱），五下國語〈給女兒的一封信〉講義 S9（書信結構：稱謂語、敘事、說理、總結、祝福語、署名、日期）。
- **資料缺口（請使用者決定）**：講義資料夾的「003.應用文(書信類).docx」是空檔；S1 只列「書信格式、信封格式」名稱沒有內容；S9 只有各部分的名稱與順序。所以本集**不做信封格式**，各部分在信紙上的**左右位置只做示意**（由上到下排，畫面標「示意」），不教「頂格、靠右」等規則。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F3、F4）：把結構表的七格合成五個部分：稱謂語、正文（敘事＋說理＋總結）、祝福語、署名、日期。「正文」這個名稱是本集為了好記而加的。
- R2（由 F4）：給三年級的正文白話：先說一件事 → 說我的想法 → 做總結。S9 的範例是父親寫給女兒的說理信，本集只借它的順序。
- R3：各部分在信紙上的左右位置講義沒有寫，畫面只示意「由上到下」的順序，標「位置示意」。

## 機制（C1）

1. 書信寫給一個人看（F3）。
2. 五個部分照順序由上到下（F4、R1）。
3. 正文：一件事 → 想法 → 總結（F4、R2）。

## 比喻（標示）

- 人偶、信紙槽位、工作牌、積木、放大鏡：比喻或示意，非原文；信紙各部分的位置是示意。

## 不放進動畫的內容與理由

- 信封格式：講義只有名稱，沒有內容（空檔），本集不做；待使用者提供資料或決定。
- 稱謂語與祝福語的各種寫法（如提稱語、敬辭）：講義沒有，不教。
- S9 範文（劉墉〈給女兒的一封信〉）內容：課文受著作權保護，只借結構，不上畫面。

## 禁用清單

置中文字＋漸層淡入、無出處數字、炫技動效、小於 22px 的字、定義卡與長句、整段文章上字、只換顏色不演出的文字卡片。

## 風格

沿用前集黑板舞台；信紙是白粉筆直立長方形；槽位黃虛線框，亮起時填淡黃；工作牌 34px、短語 30px、示範句 36px、題目卡 40px 以上。
