# 作文寫作教學動畫

給國小學生看的作文教學動畫網頁，黑板風格，一次講一個概念，可以停在任何一段講解。依課程年級順序製作，目前先做記敘文。

## 動畫清單

| 集 | 年級／單元 | 主題 | 長度 | 開啟 |
|---|---|---|---|---|
| 1 | 三上・記敘文（寫人） | 寫人的文章怎麼搭骨架？（A 真人真事／B 思想感情、蒐集材料、並列、鳳頭豬肚豹尾、一段只放一件事） | 9 段・約 2 分鐘 | [g3-01-person-skeleton/index.html](g3-01-person-skeleton/index.html) |

## 怎麼使用

- 下載後直接雙擊各集的 `index.html` 就能播放，不需要網路伺服器。
- 鍵盤：空白鍵播放／暫停，左右方向鍵切換段落，F 鍵全螢幕。
- 控制列有「標註工具」，上課時可以在畫面上畫線、寫字（只存在當下的頁面，重新整理就消失）。
- 網址加上 `?embed=1` 只顯示舞台和字幕，方便嵌入其他頁面。

## 每集資料夾裡有什麼

| 檔案 | 用途 |
|---|---|
| `index.html` | 動畫本體（單一檔案） |
| `brief.md` | 教學目標、事實表（每句字幕的出處）、分鏡 |
| `timing.json` | 分段、秒數與字幕 |
| `eps-scenes.js` | 場景程式（已組裝進 index.html，留存供修改） |

## 出處與說明

- 教學方法依據：楊裕貿〈寫作課程規劃與有效的寫作教學──輕鬆閱讀、快樂寫作〉研習講義，以及三年級寫作學習單。
- 「鳳頭、豬肚、豹尾」是原講義的比喻；積木、泡泡等是動畫的視覺比喻。
- 動畫裡的示範短文〈我的老師〉是依講義的段落結構自編，人名為虛構。
- 每集動畫的字幕與畫面文字，交付前經另一家族模型做過「畫面 vs 講義原文」事實一致性審查。
