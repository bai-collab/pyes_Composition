# 作文寫作教學動畫

## 怎麼使用

- 點上表的「線上播放」就能在瀏覽器直接看（GitHub Pages）。
- 也可以下載後直接雙擊各集的 `index.html` 播放，不需要網路伺服器。
- 鍵盤：空白鍵播放／暫停，左右方向鍵切換段落，F 鍵全螢幕。
- 控制列有「標註工具」，上課時可以在畫面上畫線、寫字（只存在當下的頁面，重新整理就消失）。
- 網址加上 `?embed=1` 只顯示舞台和字幕，方便嵌入其他頁面。

## 每集資料夾裡有什麼

| 檔案 | 用途 |
|---|---|
| `index.html` | 動畫本體（單一檔案） |
| `brief.md` | 教學目標、事實表（每句字幕的出處）、分鏡 |
| `timing.json` | 分段、秒數與字幕 |
| `*-scenes.js` | 場景程式（已組裝進 index.html，留存供修改） |

## 出處與說明

- 教學方法依據：楊裕貿〈寫作課程規劃與有效的寫作教學──輕鬆閱讀、快樂寫作〉研習講義、作文寫作要領、寫作課程設計，以及三年級寫作學習單、作文仿寫學習單；書信集的書信結構參考五下國語〈給女兒的一封信〉課文講義的結構表（只借結構，不用課文內容）。讀書報告集依國語五上備課指引〈讀書報告〉的三部分與「如何寫讀書心得報告」講義；示範書〈小狐狸的燈籠〉與作者、出版社都是虛構的。議論文集參考〈如何保護山林〉議論文與說明文大綱、作文仿寫學習單的論點／論據／方法／結論，以及議論文引導講義；四段分法（主張＋理由／方法／方法／重申）依教學者指示，示範〈如何做一個好學生〉為自編。
- 「鳳頭、豬肚、豹尾」是原講義的比喻；積木、泡泡等是動畫的視覺比喻。
- 動畫裡的示範短文〈我的老師〉、記景集、寫人進階集、寫事進階集與說明文集的示範句與範例短語，都是依講義的段落結構自編，人名為虛構；校園地圖、溜滑梯、圖書館與借書區、閱讀區、杯中綠豆、書桌是示意圖，綠豆天數是示範；事理集借用作文仿寫學習單〈比讀書更重要的事〉的四段排法，內容自編。
- 每集動畫的字幕與畫面文字，交付前經另一家族模型做過「畫面 vs 講義原文」事實一致性審查。
