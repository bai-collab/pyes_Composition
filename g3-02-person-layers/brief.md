# 一段裡面怎麼排？——三年級記敘文（寫人）第二集

- 觀眾：國小三年級學生（三上「記敘文寫人類」第二週：分析各段層次、設計細目；搭配開頭結尾法）。
- 學完能說出：
  1. 一段裡面先寫幾句真實的細節（a），最後用一句感覺收尾（b）。
  2. 最後一段反過來：事實少、感覺多；每段的重點藏在 b，全篇的重點藏在最後一段 B。
  3. 開頭可以「破題」，一開始就說出題目；結尾可以寫「希望」或「感想（感謝）」。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g3-02-source-excerpts.md`）：楊裕貿〈寫作課程規劃與有效的寫作教學──輕鬆閱讀、快樂寫作〉研習講義（S1、S3）與三年級學習單（S5、S6）。
- 接續第一集 `g3-01-person-skeleton`：沿用積木比喻、A 藍／B 橘配色與自編示範短文〈我的老師〉。

## 自編示範短文〈我的老師〉（第二版：依 F1 改成一句一層的斷句；內容與第一集相同，人名虛構，非原文）

| 段 | 層（以句號分） | a／b | 對應細目（F6） |
|---|---|---|---|
| 一 | ①我的級任老師是林老師。 | a | 名字 |
|  | ②她個子小小的，頭髮短短的。 | a | 身材、五官 |
|  | ③她戴著圓圓的眼鏡，每天都穿球鞋。 | a | 五官、服裝 |
|  | ④她看起來像一位活力滿滿的大姐姐。 | b | 感覺 |
| 二 | ①林老師很有耐心。 | a | 個性 |
|  | ②有一次我的數學題算錯了三次，她沒有生氣，蹲在我旁邊，一步一步陪我再算一遍。 | a | 舉例 |
|  | ③我覺得老師像一盞溫暖的燈。 | b | 感覺 |
| 四 | ①老師每天認真教我們、陪我們。 | a | 每天的工作 |
|  | ②我想，她一定很辛苦。 | b | 感覺 |
|  | ③我希望老師每天都健康、快樂。 | b | 希望 |

- 第四段只有一句 a：示範 B 段「事實少、感覺多」（F4 的 aa＋bbb 是講義範例的比例，動畫只說「a 少、b 多」，不宣稱固定句數）。
- 結尾的另一種寫法（感想〔感謝〕法，自編）：「我好感謝林老師，有她陪著我們學習，我覺得好幸福。」

## 比喻（標示）

- 一句＝一顆珠子：a 是藍色珠子，b 是橘色蝴蝶結，把珠子綁成一串：比喻，非原文。
- 剪刀沿句號剪開：視覺化 F1 的「打（ ）」，比喻。
- 開頭＝門、結尾＝出口：比喻，非原文。
- 第一集「骨架」、第二集「長肉」：使用者的說法，比喻，非原文。
- 註：S1 文章架構設計把最後一段的「感覺」標成 a，但同講義 B 段是 aa＋bbb，且 F2 規定感情語句標 b；動畫一律把感覺句當 b。
- 積木：沿用第一集，比喻。

## 不放進動畫的內容與理由

- 原講義範文（含真實人名、舊課文）：照 Q3 決定，用自編短文。
- 其他開頭結尾法（原因法、懷念法、結果法）：講義在範文分析裡出現，但三上學習單只教破題、希望、感想（感謝）；留到後面集數。
- 對話的三種寫法、摹寫修辭、段意指導（SVO 法等）：屬第二週其他練習，避免一集塞太多。
- 「aaaa」「bbb」的確切個數：講義是範例比例，動畫不寫死句數。

## 禁用清單

置中文字＋漸層淡入、無出處數字、炫技動效、小於 22px 的字、整段文章一次上字（一律逐句出現）、只換顏色不演出的文字卡片。

## 風格

沿用第一集黑板舞台；a 用粉筆藍（#7fb6d9），b 用粉筆橘（#e8875b），強調用黃（#f2c14e）。範文逐句出現，每句字級 ≥ 30px。
