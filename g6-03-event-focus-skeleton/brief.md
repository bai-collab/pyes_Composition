# 先放最特別的那一刻——六年級記敘文（寫事，進階）第一集（骨架，表徵版）

- 觀眾：國小六年級學生（六下記敘文敘事類，題目如〈一件特別的事〉〈最有趣的事〉〈最有意義的事〉）。
- 本集定位：六下寫事進階的第一集＝練「骨架」（下一集 g6-04 練長肉，練習段從本集練習的骨架長出來）。
- 學完能說出：
  1. 〈一件特別的事〉的範圍是「一件事」，重點是「特別」；要挑一件真的特別的事來寫。
  2. 四年級學過照「原因、經過、結果」排（因果式）；六年級多學一種：**先寫結果，再寫原因、經過，最後再回到結果**（果因果式）。
  3. 四段各寫什麼（守門第⑤條）：第一段**先寫那一刻**；第二段**為何特別：起因**；第三段**為何特別：經過**；第四段**結果和感想**。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g6-03-source-excerpts.md`）：研習講義 S1、S2，寫作課程設計 S4（版本差異）。
- 和前集的區別：g4-01 教四要素、原因經過結果骨牌、時間式／事件式／因果式、原因法與結果法；g6-01 教範圍與重點、四段工作牌、用重點挑材料。本集新教的是「果因果式」，並把重點「特別」接到寫事。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F2、F3、F4）：用重點「特別」挑一件事。講義列出「特別事件」與「預測取材」，「用重點挑」是歸納的提醒（沿用 g6-01 的磁鐵）。
- R2（由 F4、F6）：果因果式排成四段時，第一段寫果 1、第二段原因、第三段經過、第四段果 2 加感想。講義只列四個部分的順序，對應成四段與第四段加 B 是本集的排法。
- R3（由 F6、F7）：果 1 寫「最特別的那一刻」，讓讀者先看到重點。講義只寫「果 1」，「那一刻」是白話說法。
- R4（由 F4、F7）：中間兩段要寫出「為何特別」（起因、經過），工作牌和題目重點連起來。

## 機制（C1）

1. 題目有範圍「一件事」和重點「特別」（F3）。
2. 用重點挑一件特別的事（F2、R1）。
3. 原本照順序：原因 → 經過 → 結果（F5）。
4. 果因果：把結果那一刻先拿到最前面，再講原因、經過，最後回到結果（F6、R2、R3）。
5. 四段工作：先寫那一刻／為何特別：起因／為何特別：經過／結果和感想；中間兩段照到重點（F4、R4）。

## 不放進動畫的內容與理由

- 講義範文（專題報告、籃球比賽等）：只借結構。
- 今昔今式：講義有列，本集只教果因果式，避免一集塞兩種。
- 段內怎麼寫（細節、對話、感覺）：留到 g6-04（長肉）。
- 「倒敘」一詞：講義表三列了「順敘、倒敘」但未定義，本集不把果因果式稱為倒敘。
