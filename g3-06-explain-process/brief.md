# 寫一件事怎麼變——三年級說明文（事物）第三集（三下歷程骨架，表徵版）

- 觀眾：國小三年級學生（三下說明文事物類，題目〈種子的發芽〉〈紙黏土的製作〉〈吹畫的製作〉）。
- 本集定位：三下說明文第一集＝練「骨架」：記錄一件事**從開始到結束**的歷程，照先後排成四段。三上兩集（g3-04、g3-05）寫「一個地方是什麼」；本集寫「一件事怎麼變、怎麼做」。依 README 第 5 節：表徵優先、文字精簡；每塊積木掛工作牌（守門第⑤條）。長肉集（段內怎麼寫）另做。
- 學完能說出：
  1. 三下的說明文要記錄「歷程」：植物怎麼長大、東西怎麼做出來。
  2. 歷程要照**由開始到結束**的次序排：照時間排（第一天、第三天、第七天）叫**時間式**；照步驟排（開始、接著、後來）叫**事件式**。
  3. 四段骨架：準備材料／前段的變化或第一步／後段的變化或接下來的步驟／總結結果；先後不能亂，要寫出第幾天、做什麼。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g3-06-source-excerpts.md`）：作文寫作要領 S3、寫作課程設計 S4（題目與蒐集內容）、研習講義 S1 與 S2（時間式、事件式）。S1 表二三下未列說明文，本集依 S3、S4。
- 和前集的區別：g3-04 的四段是「位置和整體／介紹兩處／總結用處」（空間）；本集換成「準備／前段／後段／總結」（時間）。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F2、F5、F6）：記錄植物生長適合用時間式（照第幾天排）；記錄製作適合用事件式（照步驟排）。講義只說兩種結構都適用說明文，沒有指定哪個題目用哪一種；畫面寫成「可以」，第 9 段練習讓學生自己選。
- R2（由 F4、F5、F6；延續 g3-04 R3、R4）：四段工作白話：準備材料／前段（第一步）／後段（接下來）／總結結果。講義沒有給三下說明文的四段大綱，這是本集比照 g3-04 四段骨架的排法。
- R3（由 F7；延續 g3-05 R3）：準確＝寫出第幾天、放了多少、做了什麼，例如「第三天長出白根」比「過幾天長出根」清楚。例子自編。
- R4（由 F8；延續 g3-04 R1）：第四段總結結果，這篇不寫心得感想。只說「這篇」，不說成所有說明文的定義。

## 機制（C1）

1. 三下說明文記錄「歷程」：一件事從開始到結束怎麼變、怎麼做（F2）。
2. 次序：由開始到結束（F4）。
3. 兩種排法：時間式照時間先後、事件式照步驟先後（F5、F6）。
4. 骨架：準備材料 → 前段 → 後段 → 總結結果（R2、R4）。
5. 先後不能亂、要寫出第幾天（F4、F7、R3）。

## 自編示範短文〈種子的發芽〉（依 F2、F4、F5 結構自編；不寫學校名稱；不沿用講義例句）

| 段 | 工作牌 | 內容 |

| 二 | 前三天 | 第一天，綠豆喝了水，變得又大又胖。第三天，綠豆裂開，長出一條白色的根。 |

## 吹畫三步驟（第 5 段事件式示範，自編）

- 開始：在紙上滴幾滴顏料。接著：用吸管把顏料吹開。後來：放著等它晾乾。

## 不放進動畫的內容與理由

- 講義的「縱、橫、總」結構式：講義只列名稱，沒有說明，本集不使用。

## 禁用清單
