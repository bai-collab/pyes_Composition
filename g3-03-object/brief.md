# 寫一樣東西，眼睛怎麼走？——三年級記敘文（狀物）第三集

- 觀眾：國小三年級學生（三下第一個寫作單元「記敘文狀物類」，題目如〈我的教室〉）。
- 學完能說出：
  1. 寫一樣東西（或一個地方），先蒐集材料：外觀、構造、功用、難忘的事……
  2. 用「方位」排順序：站在一個地方轉頭看（定點觀察），或一邊走一邊看（移步換景）；照一個順序寫，例如前、左、後、右。
  3. 用「總分式」開頭：先總說整體，再一個方向一個方向分說；骨架仍是前面寫 A、最後一段寫 B。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g3-03-source-excerpts.md`）：楊裕貿研習講義（S1、S2、S3）、寫作課程設計（S4）、三年級學習單（S6）。
- 接續第一、二集：沿用黑板舞台、積木（A 藍／B 橘）與「a 珠子＋b 蝴蝶結」的表徵；第一集練骨架、第二集練長肉，本集把骨架與長肉用在「寫物」上，新教「方位順序」。

## 自編示範短文〈我的教室〉（依講義「前→左→後→右」與總分式結構自編，非原文；不沿用講義範例句子）

| 二 | 前面和左邊（分說） | A | ①教室前面是一大片黑板，旁邊放著老師的講桌。（a）②左邊有一排窗戶，陽光從窗外照進來。（a）③坐在窗邊暖暖的，好舒服。（b） |

- 第一段開頭「我們的教室……」也是第二集教過的破題法。

## 比喻（標示）

- 視線＝手電筒光束、腳步＝地上的腳印：比喻，非原文。
- 積木、a 珠子、b 蝴蝶結、骨架／長肉：沿用第一、二集的比喻。
- 教室平面圖與小人：示意圖，非原文。

## 不放進動畫的內容與理由

- 講義的教室範例句子（S2、S3）：只取「前→左→後→右」的順序，不照抄句子；範文自編。
- 因果式、順敘倒敘、修辭技巧：三下狀物也要學，但一集只教方位與總分，留到後面。
- 〈我的書包〉〈我的鉛筆盒〉等 S3 版題目：本集用 S1、S4 的〈我的教室〉與〈我家的客廳〉。
- 移步換景只做對照：本集示範短文用定點觀察；講義沒有規定哪種題目用哪種，動畫不做這類斷言。
