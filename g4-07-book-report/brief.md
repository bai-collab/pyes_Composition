# 一份讀書報告有三個部分——四年級應用文（讀書報告）第一集（格式骨架，表徵版）

- 觀眾：國小四年級學生（四下應用文報告類，習寫〈讀書報告〉）。
- 本集定位：讀書報告第一集。讀書報告是把讀過的好書**推薦給別人**；分三個部分：**書籍資料**（書的身分證）、**內容摘要**（把長的內容濃縮成重點，用自己的話）、**讀後感想**（從最感動的地方寫）。三部分裡，書籍資料誰寫都一樣，內容摘要每個人挑的重點不太一樣，讀後感想每個人都不一樣。
- 學完能說出：
  1. 讀書報告的三個部分和順序。
  2. 內容摘要要挑重點、用自己的話，不是整段抄；而且要照**開始、經過、結尾**寫，讓**沒看過這本書的人**也知道故事怎麼發展（使用者 2026-10-23 指示）。
  3. 讀後感想從印象最深或最感動的地方寫起。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g4-07-source-excerpts.md`）：研習講義 S1（四下報告類週規劃與寫作知識），國語五上備課指引〈讀書報告〉S10（三部分與寫作引導），「如何寫讀書心得報告」S11（不可東抄西抄、用自己的話）。
- 和前集的區別：說明文、書信是寫自己知道的事；讀書報告是寫「讀過的一本書」。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F4）：用「一樣／差不多／不一樣」三個標籤表示三部分隨人不同的程度。「差不多」是本集對「因人取材不同而有異」的白話。
- R2（由 F3、F5、F6）：內容摘要的三個重點照「開始、經過、結尾」排。「讓沒看過的人也知道故事發展」是使用者 2026-10-23 的指示；講義 S10 只寫「重點式簡單介紹」，「開始、經過、結尾」借自 S1、S2 記敘事件的寫法（原因經過結果、開始到結束），不是讀書報告講義的原文。
- R3：S11 列的八項格式（書名、著者、出版項、頁數、內容大意、讀後心得、評語、附註）比較完整，給四年級用 S10 的三部分；本集不教頁數、評語、附註。

## 機制（C1）

1. 讀書報告＝把書推薦給別人（F2）。
2. 三部分：書籍資料 → 內容摘要 → 讀後感想（F3）。
3. 摘要：挑重點、照開始→經過→結尾、用自己的話，不抄；沒看過的人也看得懂（F3、F5、F6、R2）。
4. 感想：從最感動處寫（F3）。
5. 誰寫都一樣／差不多／不一樣（F4、R1）。

## 自編示範（虛構的書，不用真實書名與作者）

- 書籍資料：書名〈小狐狸的燈籠〉、作者 林小雨（虛構）、出版者 星星出版社（虛構）、出版年月 二〇二〇年五月（示意）。
- 內容摘要（開始、經過、結尾）：開始——小狐狸在森林迷路了；經過——牠提著燈籠找路，燈籠被風吹熄又重新點亮；結尾——燈籠照亮了回家的路。短語：森林迷路了、提燈籠找路、燈籠照回家。
- 抄的長句（✗）：「那天晚上，風呼呼的吹，樹葉沙沙的響，小狐狸提著燈籠，一步一步走進黑黑的森林……」
- 自己的話（✓）：「小狐狸提著燈籠，找到回家的路。」
- 讀後感想第一句：「最讓我感動的是，燈籠被風吹熄了，小狐狸還是重新把它點亮。」

## 不放進動畫的內容與理由

## 禁用清單

置中文字＋漸層淡入、無出處數字、炫技動效、小於 22px 的字、定義卡與長句（例外：第 6 段被檢查的抄寫長句，依 README 第 5 節「判斷段要讓被判斷的句子出現」）、整段文章上字、只換顏色不演出的文字卡片。

## 風格

沿用前集黑板舞台；報告紙白粉筆直立長方形，三個黃虛線槽位；身分證是白框卡片＋左上一個小書本圖示；工作牌 34px、卡片字與短語 30px、示範句 36px、題目卡 40px 以上。
