# 寫一件事，先排好時間——四年級記敘文（敘事）第一集（骨架）

- 觀眾：國小四年級學生（四上第一個寫作單元「記敘文敘事類」，題目如〈戶外教學〉）。
- 本集定位：新文體的第一集＝練「骨架」（依使用者分集邏輯；下一集 g4-02 再練敘事段落的「長肉」）。
- 學完能說出：
  1. 寫一件事要交代四要素：人物、時間、地點、事件；事件又有原因、經過、結果。
  2. 先蒐集材料（為什麼去、看到哪些景物、發生什麼特別的事），再照一種順序排：時間式、事件式或因果式。
  3. 排成四段骨架：開頭寫原因，中間兩段寫重點（看到的、特別的事），最後一段寫感想（B）；開頭結尾可用原因法、結果法。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g4-01-source-excerpts.md`）：楊裕貿研習講義（S1、S2、S3）、寫作課程設計（S4）。
- 接續前三集：沿用黑板舞台、積木（A 藍／B 橘）與泡泡；第三集的方位順序在本集換成「時間順序」。

### 解說推論（依講義範例歸納，非講義定義，畫面要寫成「像範例這樣」）

- R1（由 F9）：原因法＝開頭先寫為什麼去、什麼時候去。講義只以範例標示「原因法」，沒有寫定義。
- R2（由 F9）：結果法＝結尾寫事情最後怎麼結束（例如回到家、離開）。講義只以範例標示「結果法」，沒有寫定義。

## 機制（C1）

1. 一件事要被讀懂，得同時交代四樣東西：誰、什麼時候、在哪裡、做了什麼（F1）。
2. 「做了什麼」本身是一串：先有原因，推動經過，最後得到結果（F1）。
3. 寫之前先把材料收進來：為什麼去、看到什麼、發生什麼特別的事（F4）。
4. 材料要排隊：可以跟著時間走、跟著事情一件接一件走，或跟著原因推到結果走；選一種（F6、F3）。
5. 排成四段：開頭交代原因，中間兩段放重點，最後一段寫結果與感想（F7、F8）；開頭結尾各有範例寫法（F9、R1、R2）。

## 表徵對照（C2）

| 概念元素 | 表徵 | 照原理動的規則 | 比喻限制 |
|---|---|---|---|
| 四要素 | 一幅四格拼圖「一件事」：人偶、時鐘、地圖釘、動作箭頭四塊 | 四塊都卡進去，圖才完整；拿掉一塊就出現空洞 | 真實文章的四要素不一定都在同一句 |
| 原因→經過→結果 | 一排骨牌 | 推倒第一張（原因），中間一張張倒（經過），最後一張倒下撞響鈴（結果） | 骨牌暗示一定會發生，真實事情不一定 |
| 從句子找四要素 | 句子裡的四個詞亮起、飛進拼圖的四個空格 | 詞的顏色＝要素顏色 | 只示範一句 |
| 蒐集材料 | 遊覽車旁冒出三個圖示泡泡：問號、眼睛、驚嘆號 | 一個泡泡＝一類材料 | 圖示代表類別，不是全部 |
| 時間式 | 太陽沿著弧線從東走到西；太陽每到一個位置，地面冒出一個小場景 | 太陽位置＝時間先後 | 太陽只表示「時間往前走」，不是真實時刻 |
| 事件式 | 曬衣繩上依序夾上三張照片 | 由左到右＝事情先後 | 照片暗示畫面，事件也可以是聲音、感受 |
| 因果式 | 第 3 段的骨牌 | 前一張推動下一張 | 同上 |
| 選一種 | 三條小軌道（太陽弧、曬衣繩、骨牌）並排，一條亮起 | 一篇文章選一條主線 | 講義沒規定不能混用，畫面只說「選一種」 |
| 四段骨架 | 前三集的積木，長度 1：2：2：1，積木上只有圖示 | 長的兩塊＝重點段 | 1：2：2：1 是第一集講義的分量建議 |
| 開頭原因法／結尾結果法 | 一扇「進門」：門一開看到問號（為什麼去）；一扇「出門」：遊覽車開回學校 | 進門＝開頭、出門＝結尾 | 依範例歸納（R1、R2） |

## 不放進動畫的內容與理由

- 講義範文（安平古堡、墾丁、中正紀念堂；含政治人物與舊課文）：只借結構，範文自編。
- 果因果式、今昔今式、聯想式：S2 有列，但四上要求的是時間式、事件式、因果式。
- 段落內的敘寫層次、觀察與修辭：留到 g4-02（長肉）。
- 懷念法：第一版有小字，第二版為減少文字拿掉。
- 自編範文其他句子：第二版只在第 4 段用第一句，第 8 段用四個時間場景圖示代替句子。
