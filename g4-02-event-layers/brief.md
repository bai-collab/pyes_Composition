# 一段裡面也要排隊——四年級記敘文（敘事）第二集（長肉，表徵版）

- 觀眾：國小四年級學生（四上「記敘文敘事類」，接續 g4-01 骨架）。
- 本集定位：新文體的第二集＝練「長肉」（使用者分集邏輯）。依專案 README 第 5 節「表徵優先、文字精簡」：畫面文字每段除標題外最多約 4 個短標籤、每個 ≤ 6 字；範文最多一句；解釋放字幕。
- 學完能說出：
  1. 四塊骨架排好後，每一段裡面的句子也要排隊：照事情的「開始、接著、後來」，照眼睛「由上而下」，或照「原因、經過、結果」。
  2. 一段先寫幾句真實的細節（a），最後一句寫感覺（b）。
  3. 中間的重點段要寫多一點；每段的重點藏在 b，全篇的重點藏在最後一段 B。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g4-02-source-excerpts.md`）：楊裕貿研習講義（S1、S2、S3）。
- 接續 g4-01：沿用同一篇自編〈戶外教學〉、四塊積木與場景圖示（遊覽車、溫室、松鼠、學校）、骨牌；沿用 g3-02 的 a 珠子＋b 蝴蝶結。

## 機制（C1）

1. 骨架只決定「這段寫什麼」，段裡的句子還要決定「先寫哪句、後寫哪句」（F3、F7）。
2. 寫一件事的經過，句子跟著事情走：開始、接著、後來（F3）。
3. 寫看到的景物，句子跟著眼睛走：由上而下、由遠而近（F3、F8）。
4. 寫為什麼會這樣，句子跟著原因推到結果（F3）。
5. 每一段的細節句（a）排完，最後用一句感覺（b）收起來；重點段的 a 比較多（F1、F5、F6），各段的 b 匯成全篇的 B（F2）。

## 不放進動畫的內容與理由

- 講義段內例句（升旗、籃球、山頭日出、校園植物專題等）：只借次序，不照抄。
- 由遠而近、由外而內、總分、並列等其他段內次序：字幕提一句「還有別的順序」，畫面不另示範。
- 觀察與修辭：四上也要學，留到後面的修辭專集。
- 對話、開頭結尾法：已在 g3-02、g4-01 教過。

## 禁用清單

置中文字＋漸層淡入、無出處數字、炫技動效、小於 22px 的字、每段超過約 4 個短標籤（第 3、5、6 段例外：另有 3～4 個對應圖示的短語，因使用者要求字幕關鍵詞也出現在黑板內）、整段文章上字（全集範文只出現一句）、只換顏色不演出的文字卡片。
