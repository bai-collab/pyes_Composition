# 寫一件事怎麼做——四年級說明文（事理）第一集（骨架，表徵版）

- 觀眾：國小四年級學生（四上說明文事理類，題目〈我的讀書方法〉〈書桌的整理方式〉〈掃地的方式〉）。
- 本集定位：說明文事理類第一集＝練「骨架」：寫一件事「怎麼做」，照「問題 → 原因 → 方法 → 結論」排成四段。三年級四集寫「東西是什麼、怎麼變」；本集寫「事情怎麼做」。依 README 第 5 節：表徵優先、文字精簡；每塊積木掛工作牌（守門第⑤條）。長肉集另做。
- 學完能說出：
  1. 四上說明文寫的是**方法**：讀書、整理書桌、掃地，都是在說一件事怎麼做。
  2. 四段骨架：第一段**提出問題**（書桌怎麼了）、第二段**分析問題**（為什麼會亂）、第三段**解決問題**（怎麼整理）、第四段**結論**（整理的好處）。
  3. 方法段用「**首先、其次、最後**」一步一步寫。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g4-05-source-excerpts.md`）：作文寫作要領 S3（題目、蒐集內容、闡明事理、〈如何保護山林〉說明文大綱），寫作課程設計 S4，作文仿寫學習單 S8（四段說明文：提出問題、分析問題、解決問題、結論；方法段首先、其次、最後）。
- 和前集的區別：g3-04 四段是「位置和整體／介紹兩處／總結用處」；本集換成「問題／原因／方法／結論」。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F1、F2、F3）：四上事理類的題目都在說「方法」，所以本集說成「寫一件事怎麼做」。講義寫的是「闡明事理」，「怎麼做」是本集給四年級的白話說法。
- R2（由 F4、F7）：把 S8 的四段套到〈書桌的整理方式〉：書桌怎麼了／為什麼會亂／怎麼整理／整理的好處。S8 原本的題目〈比讀書更重要的事〉比較像講道理的文章，本集只借它的四段排法；〈如何保護山林〉的「現況 → 計畫 → 預期成效」支持同樣的順序。
- R3（由 F4、F8）：第四段寫結論＝再說一次整理的好處（看得到的結果，例如找得到東西），不寫「我好開心」這類心情。只說「這篇」。
- R4（由 F5）：方法有好幾個步驟時，用首先、其次、最後排，一個詞帶一個動作。

## 機制（C1）

1. 事理說明文寫「怎麼做」（F1、R1）。
2. 先提出問題，再分析原因（F4、F6）。
3. 方法照首先、其次、最後排（F5、R4）。
4. 結論說好處，不寫心情（F4、R3）。
