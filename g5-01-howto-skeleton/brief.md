# 寫一篇讓人相信的「如何」——五年級議論文（如何型）第一集（骨架，表徵版）

- 觀眾：國小五年級學生（五上議論文如何型，題目〈如何保護環境〉〈怎樣做個孝順的孩子〉〈如何做一個好學生〉）。
- 本集定位：議論文第一集＝練「骨架」：第一段先說**主張**（論點）並給**理由**（論據），中間兩段寫**方法**（三個方法時，其中一段寫兩個），最後**再說一次主張**（重申論點）。四年級說明文寫「事情怎麼做」，目的是讓人**知道**；本集的議論文目的是讓人**相信**。依 README 第 5 節：表徵優先、文字精簡；每塊積木掛工作牌（守門第⑤條，頭尾段也有）。長肉集是否要做，等本集上線後先比對再問使用者（教訓 2026-10-23 長肉集重複）。
- **第一版修改（2026-10-24，使用者看片意見）**：原為 S1 六段（一個方法一段），使用者指出「正常來說不會到六段，都是四段來分，所以有時一段會講到兩個方法」，並選定四段為「主張＋理由／方法／方法／重申」；理由「只拚分數會忘」看不懂，改為「天天進步一點」。修改前備份 `workspace/essay-writing-animations/g5-01-brief.before-rev1.md`。
- 學完能說出：
  1. 議論文是要讓人**相信**我的看法；如何型題目要寫「**為什麼要**」和「**怎麼做**」。
  2. 骨架四段：第一段**我的主張和為什麼**、第二段和第三段**方法**（三個方法時，一段寫兩個）、第四段**再說一次主張**。
  3. 結尾要回到開頭的主張，不是換一個新想法。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F1）：「信」說成「讓人相信」；說明文的「知」說成「讓人知道」。這是本集給五年級的白話說法。
- R2（由 F2、F3）：如何型題目蒐集的是「理由和方法」，所以本集把它說成讀者心裡的兩個問題：「為什麼要？」「怎麼做？」。讀者人偶與問號泡泡是比喻。
- R3（由 U1、F7、F8）：骨架照使用者指示的四段排；三個方法分在第二、三段，同一類的方法放同一段（示範：學習上的兩個方法放第二段，生活上的一個放第三段）。「同一類放一段」是本集的推論，不是講義原文。S1 的六段大綱、S8 的四段（理由獨立一段、方法同一段）都是講義寫法，本集只在第 8 段借 S1 大綱比較頭尾。首先、其次、最後只當方法積木上的小字（F7）。
- R4（由 F6、F9）：第四段寫「再說一次主張」，回到第一段的看法；不另寫新的主張。
- R5（由 F2、F6）：把四段分成開頭、中間、結尾三組，對應「三段式」；S1 沒有寫三段式的細節，本集只用括號表示分組。

## 機制（C1）

1. 議論文要讓人相信（F1、R1）。
2. 先立主張，主張需要理由撐住，兩者都在第一段（F6、F7、U1）。
3. 方法放在中間兩段，一段可以寫兩個（U1、R3）。
4. 結尾回到開頭的主張（F4、F6、F9、R4）。

## 不放進動畫的內容與理由

- 講義範文與名人事例（S8、S12、S13 的真實人名、古籍名言）：本集只借結構，不上畫面。
- 開頭法、結尾法（S13 用問號開頭、「不但可以…還可以…」）與「論據可以舉例」的寫法（S14 什麼人、做了什麼事、得到的結果）：屬段內寫法，留到下一集是否要做再問使用者。
- 「範圍型、觀點型」題目分類、兩類題與多類題：五上不用。
- S1 六段排法、S8 理由獨立一段的排法：依使用者指示不教，避免和四段混淆（R3）；第 8 段只借 S1 大綱比較頭尾，大綱卡上不寫段號。
