# 寫一處風景，跟著腳步走——四年級記敘文（記景）第一集（骨架，表徵版）

- 觀眾：國小四年級學生（四下第一個寫作單元「記敘文記景類」，題目如〈美麗的校園〉）。
- 本集定位：新文體的第一集＝練「骨架」（下一集 g4-04 練記景的長肉）。依專案 README 第 5 節：表徵優先、文字精簡；每個承載內容的圖示旁放一個 ≤ 6 字、和字幕一致的短語；範文最多一句。
- 學完能說出：
  1. 先審題：題目有「範圍」（寫哪裡）和「重點」（寫成什麼樣子）；〈美麗的校園〉的重點是「美麗」。
  2. 先蒐集材料：景色、動物、人物活動；再決定怎麼走：邊走邊看（移步）或站著看（定點）。
  3. 骨架：先總說，再一站一段分說，重點寫在第二、三段，每段都要寫出「美麗」，最後一段寫感覺。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g4-03-source-excerpts.md`）：楊裕貿研習講義（S1、S2、S3）、寫作課程設計（S4）、三年級學習單（S6）。
- 和 g3-03（狀物）的區別：g3-03 寫一個房間，用「站著轉頭看」排方位；本集寫一大片風景，主角是「審題的重點」與「邊走邊看、一站一段」。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F4、F5、F11）：範圍觀點型題目的「重點」要在主體每一段都寫到，不然就文題不符。講義只寫「重點寫在二、三段」「文題相符」，「每段要寫美」是依此歸納的提醒。

## 機制（C1）

1. 題目由兩個零件組成：範圍決定「寫哪裡」，重點決定「寫成什麼樣子」（F4）。
2. 寫之前把材料收進來：景色、動物、人物活動（F3）。
3. 決定眼睛怎麼走：邊走邊看，走到哪寫到哪；或站在一處轉頭看（F6、F7）。
4. 一站一段排成骨架：先總說整個地方，再一站一段分說，最後寫感覺（F5、F8、F9）。
5. 每一段都要照到「重點」，不然就文題不符（F5）。

## 表徵對照（C2）

| 概念元素 | 表徵 | 照原理動的規則 | 比喻限制 |
|---|---|---|---|
| 範圍 | 題目卡上框出「校園」的方框（像地圖框） | 框住的地方才寫 | 範圍有時是一個時段，不一定是地方 |
| 重點 | 放大鏡停在「美麗」上 | 放大鏡照到的，每段都要寫到 | 觀點型題目只有重點、沒有範圍 |
| 範圍型 vs 範圍觀點型 | 兩張題目卡並排：〈我的校園〉只有方框；〈美麗的校園〉有方框＋放大鏡 | 多一個零件，就多一個要寫到的要求 | 只示範記敘文 |
| 蒐集材料 | 校園圖上冒出三個泡泡（使用者 2026-10-22 指定）：溜滑梯、稻穀、跑步的人 | 一個泡泡＝一樣真的看得到的材料（溜滑梯、稻穀屬景色；跑步的人屬人物活動） | 只示範三樣，講義還有動物等 |
| 移步換景 | 校園地圖上一串腳印依序走過三站：校門、操場、花園 | 腳印停的地方＝一段要寫的地方 | 移步不一定照地圖順序，也可以自由行（F6） |
| 定點觀察 | 小人站在一處，視線光束轉一圈 | 對照用，沿用 g3-03 | 同 g3-03 |
| 一站一段 | 每一站的小圖掉進一塊積木 | 站數＝主體段數 | 講義只說每段寫一件事，站數可多可少 |
| 先總說再分說 | 第一塊積木裝整張縮小地圖，後面積木各裝一站 | 總→分→分 | 也有總分總 |

## 比喻（標示）

- 方框、放大鏡、腳印、圖示泡泡、星星、積木：比喻，非原文；地圖是示意圖。
- 溜滑梯圖示依網路照片（親子部落格的學校實景照）重繪為粉筆線條示意，不嵌入照片；畫面與公開檔案不寫學校名稱（個資與公開掃描規則）。

## 不放進動畫的內容與理由

- 講義記景例句（安平古堡、墾丁、山頭日出等）：只借結構。
- 順敘、倒敘、觀察、修辭：四下也要學，留到 g4-04（長肉）或修辭專集。
- 觀點型題目（應變）：只在對照卡提一次「還有只有重點的題目」，不展開。
- 縱向、因果（S3 版本）：本集採 S1 的方位式、總分式。

## 禁用清單

置中文字＋漸層淡入、無出處數字、炫技動效、小於 22px 的字、定義卡與長句、整段文章上字、只換顏色不演出的文字卡片。
