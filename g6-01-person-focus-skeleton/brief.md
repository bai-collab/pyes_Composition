# 中間每一段，都寫那個「重點」——六年級記敘文（寫人，進階）第一集（骨架，表徵版）

- 觀眾：國小六年級學生（六上記敘文寫人類，題目如〈一個勇敢的人〉〈最感謝的人〉〈最難忘的人〉）。
- 本集定位：六上寫人進階的第一集＝練「骨架」（下一集 g6-02 練長肉，練習段從本集練習的骨架長出來）。依專案 README 第 5 節：表徵優先、文字精簡；圖示旁放 ≤ 6 字短語；範例短語每行 ≤ 7 字；範文最多一句。
- 學完能說出：
  1. 三年級的〈我的老師〉只有範圍；六年級的〈一個勇敢的人〉多了重點「勇敢」。
  2. 四段各寫什麼（使用者 2026-10-23 指示）：第一段**簡介這個人**（她是誰、長什麼樣子）；第二、三段寫**為什麼說她勇敢**（一段一件事）；最後一段寫**感想**。
  3. 重點要寫在第二段到倒數第二段；中間段不再只是外表、個性、興趣排排站。
  4. 從蒐集到的材料裡，外表放進第一段簡介，顯出勇敢的事放進中間段；中間寫成別的就文題不符。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g6-01-source-excerpts.md`）：研習講義 S1、S2，寫作課程設計 S4（版本差異），記人學習單 S5。
- 和前集的區別：g3-01 教寫人的並列骨架（外表、個性、興趣、感想）；g4-03 在記景教過「範圍和重點」。本集把「重點」帶回寫人：中間段從「他有什麼」換成「他做了什麼事，顯出重點」。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F5、F7、F8）：挑材料時，挑「能顯出重點的事」放進中間段。講義只寫「預測取材」「文題相符」與〈可愛的妹妹〉的例子，「用重點挑材料」是依此歸納的提醒。
- R2（由 F10；使用者 2026-10-23 指示「第一段要寫甚麼…你少了第一段的描述」）：第一段先簡介這個人——她是誰、長什麼樣子——讓讀者先認識她；外表材料放這裡。講義寫的是「外形」「簡介」，「她是誰、長什麼樣子」是白話說法。

## 機制（C1）

1. 題目多了一個零件：〈我的老師〉只有範圍；〈一個勇敢的人〉有範圍「一個人」和重點「勇敢」（F3）。
2. 四段分工：第一段簡介她是誰、長什麼樣子；第二、三段寫為什麼說她勇敢；最後一段寫感想（F4、F8、F10、R2）。
3. 中間段換內容：從「個性、興趣」換成「一件件顯出重點的事」，像〈可愛的妹妹〉的唱歌可愛、睡覺可愛（F2、F5）。
4. 用重點挑材料：蒐集來的材料裡，外表放第一段簡介，顯出勇敢的事才進中間段（F6、F7、F10、R1、R2）。
5. 檢查：每段都照到重點才文題相符；最後一段寫感情（F8、F9）。

## 表徵對照（C2）

| 概念元素 | 表徵 | 照原理動的規則 | 比喻限制 |
|---|---|---|---|
| 範圍 | 題目卡上藍色虛線框住「一個…人」 | 框住的對象才寫（沿用 g4-03） | 範圍不一定是人 |
| 重點 | 黃色放大鏡停在「勇敢」上（沿用 g4-03） | 放大鏡照到的，中間每段都要寫到 | 觀點型題目只有重點 |
| 四段分工 | 四塊積木各掛一個工作牌：一「她是誰」（頭像＋問號）、二三「為何說她勇敢」（放大鏡投光、亮星）、四「感想」（愛心） | 工作牌決定那一段裝什麼；只有中間兩塊被放大鏡照到 | 講義說「第二段到倒數第二段」，段數多時中間段都要；工作牌是比喻 |
| 中間段換內容 | 上排舊骨架（外表、個性、興趣、感想）中間兩塊翻面，變成兩件事 | 翻面＝換成顯出重點的事 | 翻面是比喻，講義只並列兩種大綱 |
| 用重點挑材料 | 一塊寫著「勇敢」的磁鐵，吸起顯出勇敢的材料卡；外表卡「綁馬尾」滑到第一段的工作牌下；「愛畫畫」留在原地變淡 | 只有「含鐵」（顯出重點）的卡會被吸 | 被留下的材料不是不能寫，只是不放進中間段 |
| 文題相符／不符 | 放大鏡照段落短句，找到關鍵字劃黃線＋綠勾；找不到變灰＋紅叉 | 沿用 g4-03 | 「關鍵字」是示意，重點也可以不明寫 |

## 不放進動畫的內容與理由

- 講義寫人範文（含真實姓名的老師、校長範文）：只借結構。
- 主題舉例式（主題句＋「記得有一次」）、段內 a 與 b 的層次：留到 g6-02（長肉）。
- 觀點型題目、其他文體：不展開。
- 六上議論文、童話、童詩：另做專集。
