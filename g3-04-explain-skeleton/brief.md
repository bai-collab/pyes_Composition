# 寫一篇解說牌——三年級說明文（事物）第一集（骨架，表徵版）

- 觀眾：國小三年級學生（三上說明文事物類，題目如〈科學博物館〉〈我的學校〉〈圖書館〉）。
- 本集定位：新文體「說明文」的第一集＝練「骨架」（下一集 g3-05 練長肉：段內怎麼說明形狀、功用等）。依 README 第 5 節：表徵優先、文字精簡；每塊積木掛工作牌（守門第⑤條）。
- 學完能說出：
  1. 記敘文寫「怎麼樣」（我去了、我覺得），說明文寫「**是什麼**」（它在哪、長什麼樣、有什麼用）。
  2. 說明文要說明事物的形狀、性質、成因、關係、功用；說法要**準確、明白**。
  3. 說明文的骨架（使用者 2026-10-23 指示改四段）：第一段**位置和整體**，中間兩段各介紹一處，第四段**總結用處**；最後一段**不寫感想、不加心情**，就像飲料的成分表只寫有什麼（使用者 2026-10-23 指定的比喻）。
- 來源（檔案 ID 與版本見 `workspace/essay-writing-animations/sources/source-ledger.md`；本集原文節錄見同資料夾 `g3-04-source-excerpts.md`）：作文寫作要領 S3（主要）、研習講義 S1、S2，寫作課程設計 S4，作文仿寫學習單 S8（四段說明文）。S1 表二三上未列說明文，本集依 S3、S4。
- 和前集的區別：前十一集都是記敘文（有 A 真人真事、B 思想感情）；本集第一次教說明文，重點是「它是什麼」與「最後一段不寫感想，改寫總結」。

### 解說推論（畫面寫成提醒，不寫成講義定義）

- R1（由 F6）：說明文骨架不寫最後一段的心得感想。講義只在〈科學博物館〉的例子裡打 ╳，本集畫面寫「這篇不寫感想段」，不說成所有說明文的定義。
- R2（由 F1）：說明文的句子要準確、明白，例如用「有十二排書架」比「書好多好多」更清楚。講義只寫語言風格「準確、明白」，例子是本集自編。
- R3（由 F5、F6、F8）：四段工作白話：位置和整體／介紹第一處／介紹第二處／總結用處。
- R5（使用者 2026-10-23 原話「不寫感想、不加心情，就好比食物成分表一樣」）：用飲料成分表比喻說明文——只寫有什麼、多少，不寫好不好喝的心情。比喻由使用者指定，畫面標示為比喻。
- R4（由 F6、F8；使用者 2026-10-23 原話「說明文也有四段寫法」）：事物說明文的第四段不寫感想，改寫「總結」——再說一次它是什麼、有什麼用。講義〈科學博物館〉說明文大綱第四段打 ╳，S8 的四段說明文第四段是「結論：重申論點」；把兩者合成「總結用處」是本集的排法。

## 機制（C1）

1. 同一個地方可以寫成記敘文或說明文：記敘文寫「我怎麼樣」，說明文寫「它是什麼」（F2）。
2. 說明文要說的：形狀、性質、成因、關係、功用（F3）。
3. 先收材料：外形、內部結構、擺設（F5）。
4. 骨架：位置和整體 → 介紹一處 → 介紹另一處 → 總結用處；感想段打 ╳、換成總結（F6、F8、R1、R3、R4）。
5. 說法準確、明白（F1、R2）。
